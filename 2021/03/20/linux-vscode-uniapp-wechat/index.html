Linux 下使用 VS Code 开发调试 uni-app 微信小程序

发表于 2021-03-20 分类于 学习折腾 ， 配置与操作

工具及文档

  • Linux 端的微信开发者工具：dragonation/wechat-devtools

  • uni-app 文档：uni-app doc

创建 uni-app 项目

见uni-app doc 快速上手/通过 vue-cli 命令行。

导入 HBuilder X 导出的项目

如果使用 HBuilder X 开发 uni-app 程序，项目包相当于 Vue 开发时的 src 文件夹。

想要导入一个 HBuilder X 开发的 uni-app 项目，那么通过 vue-cli 创建了运行环境后，需要将项目文件复制至通过 vue-cli 创建的项目文件夹下的 src 文件夹下。

使用 HBuilder 社区的插件

如果想导入 HBuilder 社区的插件，需要把插件下载下来，手动放到某个组件文件夹。

不确定有没有更好的方法

与微信开发者工具联合调试

与微信开发者工具联合调试：执行 dev:mp-weixin 命令，编译好后会提示编译后的项目在某文件夹（dist/dev/mp-weixin），微信开发者工具导入该文件夹即可。对项目的修改会热编译，微信开发者工具能实时看到修改的效果。

另：只涉及写页面的话，通过 H5 调试会方便不少。
