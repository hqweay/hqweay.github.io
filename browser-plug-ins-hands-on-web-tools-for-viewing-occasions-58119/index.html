浏览器插件——顺手：会看场合的网页工具

发表于 2026-09-13

之前分享过一个用思源笔记数据库做网页信息收集的 demo（分享一个用数据库做网页信息收集的 demo - 链滴）。

最近把它整理成了一个浏览器扩展，取名「顺手」，也把虎鲸笔记接了进来。

思路源于在不同的网页我想进行一些快捷操作——「顺手」就做了。

在豆瓣，帮你存下书、电影和游戏；在 B 站，收下视频；在公众号、文章和技术文档里，划一句话就能保存；需要分享时，再把内容变成一张干净的卡片。

实际使用时自由度很大，可以写脚本，用 AI 从网页里提取信息。

一些值得营销时提及，比较有意思的用法：使用 AI 总结当前网页信息并跳转推特、微博等发布。

核心思路

架构上核心思路就六个词：

词一句话
连接（接什么）你自己的外部服务：内容去哪（虎鲸 / 思源）、模型用谁（AI）
提取（拿什么）从网页里挑出你要的信息
能力（做什么）动作的实现：复制 / 存笔记 / 分享图…
配方（开箱怎么做）能力 + 预设参数，就是开箱动作
场景（哪类网页）网址命中时，出现哪些动作
模式（什么情境）一组场景，一次只有一个生效

这是我最满意的地方，依旧遵循俺的设计哲学。
